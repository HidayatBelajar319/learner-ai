# Learner AI

> **Platform Pembelajaran AI Terbaik di Indonesia** - Belajar apa saja, kapan saja, dengan cara yang adaptif dan personal.

---

## 📌 Tentang Project

**Learner** adalah platform pembelajaran berbasis **Artificial Intelligence** yang dirancang untuk membantu pengguna belajar **semua mata pelajaran, bahasa, pemrograman, dan keterampilan** dengan cara yang **interaktif, adaptif, dan dipersonalisasi**.

### 🎯 Visi

Menjadi ekosistem pembelajaran AI terdepan di Indonesia yang memberdayakan setiap individu untuk belajar tanpa batas.

### 🏆 Misi

- Menyediakan akses pendidikan universal secara gratis
- Menciptakan pengalaman belajar adaptif dengan AI
- Mendorong pembelajaran yang menyenangkan melalui gamifikasi
- Meningkatkan kualitas pendidikan dengan metode terbukti

---

## ✨ Fitur Utama

### 🤖 AI Powered

- Guru, mentor, tutor, dan teman belajar virtual
- Penjelasan adaptif sesuai kemampuan
- Pembelajaran langkah demi langkah

### 📚 Pembelajaran Komprehensif

- **Semua mata pelajaran** sekolah (SD, SMP, SMA, SMK)
- **Semua bahasa** di dunia (Inggris, Jepang, Mandarin, Arab, dll.)
- **Semua bahasa pemrograman** (Python, JavaScript, Java, C++, Rust, dll.)
- **Semua bidang teknologi** (Web Dev, AI/ML, Cloud, Cyber Security, dll.)
- **Keterampilan lainnya** (Bisnis, Desain, Produktivitas, Musik, dll.)

### 🎮 Gamifikasi

- Sistem **XP &amp; Level** (10 level)
- Sistem **Badge** (100+ badge)
- Sistem **Achievement** (pencapaian khusus)
- **Daily Streak** (rantai harian)
- **Leaderboard** (papan peringkat)
- **Sertifikat** digital

### 📖 Sistem Konten

- Materi pembelajaran interaktif
- Latihan &amp; quiz adaptif
- Ujian komprehensif
- Proyek praktis
- Flashcard &amp; mind map
- Playground coding
- Animasi edukatif

### 🎯 Sistem Evaluasi

- Quiz cepat &amp; komprehensif
- Ujian harian/mingguan/bulanan
- Penilaian otomatis &amp; manual
- Umpan balik instan
- Analisis kemajuan

### 📊 Sistem Progress

- Kemajuan per topik
- Kemajuan keseluruhan
- Riwayat pembelajaran
- Analisis kelemahan
- Rekomendasi perbaikan

### 🎨 UI/UX Modern

- Desain responsif (mobile &amp; desktop)
- Mode gelap (dark mode)
- Aksesibilitas WCAG 2.1 AA
- Animasi halus
- Navigasi intuitif

### 🔒 Keamanan &amp; Privasi

- Enkripsi data end-to-end
- Perlindungan XSS &amp; CSRF
- Filter prompt injection
- Moderasi konten AI
- Privasi pengguna terjamin

## 🛠️ Teknologi

### Frontend

- **React** + **Next.js** (Framework)
- **TypeScript** (Type Safety)
- **Tailwind CSS** (Styling)
- **Headless UI** / **Radix UI** (Components)
- **Framer Motion** (Animasi)
- **Zustand** (State Management)
- **React Query** (Data Fetching)

### Backend

- **Cloudflare Workers** (Serverless)
- **Workers KV** (Key-Value Storage)
- **Workers R2** (Object Storage)
- **Workers D1** (SQL Database)
- **Durable Objects** (State)

### AI

- **Mistral AI** (Primary NLP)
- **OpenAI** / **Anthropic** (Alternatif)
- **Vector Database** (Semantic Search)
- **LangChain** / **LlamaIndex** (AI Framework)

### Lainnya

- **Git** + **GitHub** (Version Control)
- **Wrangler** (Cloudflare CLI)
- **ESLint** + **Prettier** (Code Quality)
- **Jest** + **Cypress** (Testing)

## 🚀 Cepat Mulai

### Prasyarat

- Node.js 18.x+
- npm/yarn
- Git
- Akun Cloudflare
- API Key (Mistral/OpenAI)

### Install

```bash
git clone https://github.com/hidayat3911/learner-ai.git
cd learner-ai
npm install
```

### Konfigurasi

```bash
cp .env.example .env
# Edit .env dengan API key Anda
```

### Run Development

```bash
npm run dev
# Buka: http://localhost:8787
```

### Deploy

```bash
npm run deploy
# URL: https://<NamaWeb>.<USER>.workers.dev
```
